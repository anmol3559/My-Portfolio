# 🌌 Modern Full-Stack Developer Portfolio

A performance-first, production-ready personal portfolio crafted using **Next.js 15 (App Router)**, **Tailwind CSS v4**, and **TypeScript**. Optimized with **Turbopack** for blazing-fast local development and instant hot-reloads.

## ⚡ Key Highlights & Architecture

- **Engineered Starfield Canvas Alternative:** Implemented a pure-CSS mathematical starfield configuration array, eliminating canvas-render lag and CPU overhead.
- **Tailwind v4 Isolated Keyframes:** Resolves atomic class-collisions with custom internal keyframes (`cosmic-twinkle`) for a highly stable, uniform production build.
- **Fluid UI & Responsiveness:** Enforces responsive constraints scaling fluidly up to `max-w-7xl` containers while abstracting desktop link layouts from mobile drawer mechanics.
- **Typography & Aesthetics:** Styled using an eye-friendly, deeply muted purple radial glow accent on top of a pitch-black cosmic background, rendering sharp typography via Google Inter and Space Mono.

## 🛠️ Technical Stack

- **Framework:** Next.js 15 (App Router)
- **Compiler:** Turbopack
- **Language:** TypeScript (Strict Type Safety)
- **Styling:** Tailwind CSS v4, Framer Motion
- **Deployment & Analytics:** Vercel Web Analytics
